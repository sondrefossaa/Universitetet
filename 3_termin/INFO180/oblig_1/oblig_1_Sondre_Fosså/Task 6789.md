## Task 8

A search problem can be represnented as a state search where every possible state
is a position and every possible action is an edge, often associated with a cost.
The model often contains transition model which describes how the state will
change given an action. The model can use this transition model to predict
its actions consequences and thus see if it gets closer to the goal.
Different search algorithms chagnes the soulution process. Using DFS forexample
will often get you an answer the quicker than BFS but it will not be guarateed
the best answer like with BFS. Using a heristic is a smart way to reduce
states visited in the search and can prune away bad options. An example of this
is something like google maps pathfinding. Instead of tracing the complete paths
from a to be which can be expensive. You can devide it into smaller segments and
use the straight line distance between points as a heuristic for which paths you
should check first.

## Task 9

A constraint satisfaction problem is a problem where some variables need to
satisfy a set of constraints. One example of this is map coloring. Here you
have some countries like Norway, Sweden and Denmark and some colors like Red,
Green and Blue.

The countries are the variables and the colors are the domains, which
means the possible values each variable can have. An assignment is when you
give a variable a value, forexample Norway = Red. The constraints are the
rules for which assignments are allowed. In map coloring this could be that two
countries that border each other cannot have the same color.

Consistency algorithms can be used to reduce the amount of searching needed.
They do this by removing values from the domains that cannot work in a solution.
Forexample if Sweden has to be Red and Norway cannot have the same color as
Sweden, then Red can be removed from Norways domain.

Arc consistency checks constraints between two variables. A value can be
removed if there is no possible value for the other variable that makes the
constraint true. This means the search algorithm has less possible values it
needs to check.

Generalized Arc Consistency (GAC) works in a similar way, but it can also
work with constraints that involve more than two variables. It removes a value
if there is no combination of values for the other variables that can satisfy
the constraint.

Local consistency does not always mean that the whole problem has a solution.
This is because it only checks smaller parts of the problem at a time.
Forexample if A, B and C can only be Red or Blue and they all have to have
different colors from each other, every pair can satisfy the constraint, but
there is no way to give all three a different color. The problem can therefore
be locally consistent even though there is no global solution.
